# PICHE Home Page — Version 2

Reserved for a second, independently-built implementation of the PICHE home
page, for comparison against [`version-1`](../version-1). Any stack is fine —
this folder has no dependency on `version-1`.

Once built, deploy it as its own Vercel project with this folder as the
project's Root Directory, and link it from the root `index.html` chooser.
