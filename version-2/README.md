# PICHE Home Page — Version 2

Reserved for a second, independently-built implementation of the PICHE home
page, for comparison against [`version-1`](../version-1). Any stack is fine —
this folder has no dependency on `version-1`.

It deploys as its own Vercel project with this folder as the project's Root
Directory. Nothing links to it any more — the repo root redirects straight to
version 1, so this build is reachable only at its own deployment URL.
